# From Dormouse to Hosted remote control

Start in the app, approve its request at Hosted, then return to the app and continue to phone pairing. Each screen is a fixed story of the real component. The same example code and confirmation digits run through the handoff; no account or Relay is contacted.

> This walkthrough owns no behavior. `docs/specs/hosted.md` → “Burrow enrollment”, `docs/specs/relay.md` → “Burrow side”, and `docs/specs/remote-network.md` own the app and account steps. `docs/specs/remote-security-model.md` owns phone authorization.

## Choose the network policy in the app

In Settings → Network, a new install starts at Nowhere. Choose the policy appropriate for the connections you want before enrolling. This walkthrough proceeds with Anywhere; Local networks only is also an enrollment path, with different limits on subsequent terminal connections.

## Ask to enroll remote control

Under Phones, unfold Persistent Relay. A stock Dormouse build offers Hosted enrollment here, without a self-host setup password.

<Canvas of={RemoteControl.HostedPersistentRelay} story={{ autoplay: true }} />

“Enroll remote control” gives the app two digits and an account link. Keep Dormouse open; this is the screen to read when the browser asks which computer to approve.

## Open the account link

Before launch, a signed-out browser meets the pre-launch gate described in the [account walkthrough](?path=/docs/hosted-account-walkthrough--docs). An invited tester can sign in first and then reopen the link from Dormouse. When sign-in is available, the enrollment page keeps the reason for the visit visible:

<Canvas of={SignIn.EnrollmentEntry} />

Email-code sign-in continues this request in the same page. Provider sign-in leaves the page; after returning, reopen the enrollment link from Dormouse. A stale existing login asks for sign-in again while retaining the remote-control purpose.

<Canvas of={Enrollment.StaleRemote} />

## Type the app's digits and approve

Compare the request with the app you just left. Enter its two digits. This story types `47` and checks the approval handler; its fixed fixture remains on the form so the submitted request can be inspected.

## Continue on the phone

Use **Setup phone** in the enrolled app, then follow [“4.
